# DimGDPS-Web

A fork of [web-dashers](https://github.com/web-dashers/web-dashers.github.io) for DimGDPS.

See upstream for more info.

## Run

```bash
npm install
npm start
```

Then open `http://localhost:3000`.

## Server

Proxies gameplay to `https://dimgdps.ps.fhgdps.com`.
